# 5QLN Fractal Memory

**The living formation trail.** Fractal memory for the 5QLN language, built on the **4+1 cell** (one question at the center, four steps around it), with **[Hindsight](https://github.com/vectorize-io/hindsight)** as the retrieval/consolidation substrate.

Memory becomes alive when the bounded seed stops carrying *static* context and re-forms itself each turn from Hindsight's four-way retrieval — while the axis stays sealed (the brain) and the center stays open (the question, ∞0).

## THE DECISION: 4+1, not 5×5

The fractal is the **4+1 cell**, not the 25 sub-phases.

| | Old | New — **we go with this** |
|---|---|---|
| Shape | 5×5 = **25 sub-phases** (SS, SG … VV) | **4+1** (1 center + 4 corners, the quincunx) |
| Source | [5qln-ai-initiation-11-fractal-map](https://www.5qln.com/5qln-ai-initiation-11-fractal-map/) | [dsh-5qln-codex-fractal](https://www.5qln.com/dsh-5qln-codex-fractal/) (Appendix D) |
| Word | "operates at 25 sub-phases" | "fractal used to mean 5×5 and Now it is 4+1 (same seed, true collapse to 1)" |

The 25 sub-phases are **not** discarded — Appendix D re-reads them as *the first in-zoom of a single cell, never a cap*. But the invariant is the cell: **1 center (S) + 4 corners (G, Q, P, V)**, at every depth and height, never 3+1, never 6+1.

The center is **S = ∞0 → ?** — the *question*, the signless start. The Nine Invariant Lines are the **Codex** — the grammar, K-side, held *outside* the cell and verified by the corruption watcher. The code is not the center; the question is.

## What this is

Two layers of the machine's memory:

1. **The brain** (seal-side, exists already) — remembers *structure*, never content. The axis, the calibration, the watcher. Untouched by this work.
2. **The living formation trail** (content-side, this repo) — Hindsight, retrieval, consolidation. The questions and phase-memories the brain deliberately does not hold.

The brain keeps the trail from claiming the center. The trail lives *around* the brain.
